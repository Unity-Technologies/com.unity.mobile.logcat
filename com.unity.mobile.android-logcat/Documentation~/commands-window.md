# Commands window

Run, add, and manage Android Debug Bridge (adb) and shell commands from the Android Logcat window without using an external terminal.

The Commands window contains a list of default adb commands that you can run on a connected device. You can add your own commands and assign them a category, and import or export commands as JSON.

To access the Commands window, select **Tools** > **Commands** in the [Android Logcat window](android-logcat-window.md) toolbar.
