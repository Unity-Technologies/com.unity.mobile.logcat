# Requirements and compatibility

This page contains system requirements and compatibility information for the Android Logcat package.

## Unity Editor

The Android Logcat package requires Unity 6.0 or above and the Android support module. For information on how to install the Android support module, see [Android environment setup](https://docs.unity3d.com/Manual/android-sdksetup.html).

## Supported features

The Android Logcat package supports the following features:

* Wireless and USB device connection
* Package selection
* Message log
  * Copy
  * Save
  * Clear
  * Filter by
    * Priority
    * Tag
    * Process ID
    * Text (including regular expressions)
* Auto run
* Screen capture
  * Screenshots
  * Live device screen view, with touch, key and clipboard input
  * Video recording and playback (recording is not available on Linux)
* Memory Window
* Input injection
* Stacktrace resolving
* Commands window for running and saving adb commands
