# Add a command

Add a custom command or a predefined command from the built-in catalog to the Commands window.

Add the commands to the Commands window so that you can run them from the Editor without an external terminal. Add a custom command if the catalog doesn't contain the one that you need.

## Add a custom command

To add a custom command:

1. In the Commands window, select **Add Command**.
2. In the **Name** field, enter a name for the command. In the **Command** field, enter the command to run. To run several commands in sequence, enter each command on its own line.
3. (Optional) In the **Category** list, select a category. The Search Commands window uses the category to filter commands.
4. Select **Add**.

The command appears in the **General** list.

## Add a command from the catalog

To add a command from the catalog:

1. In the Commands window, select **Search Catalog**.
2. Find a command by entering text in the search field or selecting a category button.
3. Select **Add** next to the command.

The command appears in the **General** list. In the Search Commands window, commands that you already added have the **Added** label.
